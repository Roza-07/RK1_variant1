# РК №1 — Вариант 1

Решение трёх заданий по Python из файла «РК 1.docx».

## Что находится в папке

- `chunk.py` — задание 1: функция `chunk(items, size)` с аннотациями типов.
- `test_chunk.py` — параметризованные тесты `pytest` (включая остаток, `size` больше длины списка, пустой список и неверный размер).
- `counter.py` — задание 2: защита общего счётчика с помощью `threading.Lock`.
- `main.py` — задание 3: модели `Item`, `ItemResponse` и эндпоинт `POST /items`.
- `requirements.txt` — необходимые библиотеки.
- `.gitignore` — исключения для Git.

## Как запустить в Windows (VS Code)

1. Распакуй ZIP, открой VS Code → **File → Open Folder** → выбери папку `RK1_variant1`.
2. Открой **Terminal → New Terminal**.
3. Создай виртуальное окружение:
   ```powershell
   py -m venv .venv
   ```
4. Активируй его в PowerShell:
   ```powershell
   .\.venv\Scripts\Activate.ps1
   ```
   Если PowerShell запрещает запуск скриптов, переключи терминал на **Command Prompt** и введи:
   ```cmd
   .venv\Scripts\activate.bat
   ```
   Или вообще не активируй окружение, а используй `.venv\Scripts\python.exe` вместо `python` в командах ниже.
5. Установи библиотеки:
   ```powershell
   python -m pip install -r requirements.txt
   ```
6. Проверь первое задание:
   ```powershell
   python -m pytest -v
   ```
   Ожидается: **5 passed** (4 параметризованных случая + 1 проверка ошибки).
7. Проверь второе задание:
   ```powershell
   python counter.py
   ```
   Ожидается: **800000**.
8. Запусти третье задание:
   ```powershell
   python -m uvicorn main:app --reload
   ```
9. Открой в браузере **http://127.0.0.1:8000/docs**, раскрой **POST /items**, нажми **Try it out**, вставь:
   ```json
   {
     "name": "Book",
     "price": 500,
     "tags": ["reading"]
   }
   ```
   Нажми **Execute**. В ответе появится `id: 1`. При повторном запросе будет `id: 2`.
10. Для проверки валидации отправь `"price": -100`: API вернёт статус **422**.
11. Останови сервер клавишами **Ctrl+C** в терминале.

## Для защиты

1. `chunk` нарезает список срезами `items[i:i+size]`. Тип `T` сохраняет тип элементов. Параметризация проверяет несколько входных наборов.
2. `counter += 1` — изменение общего состояния, где возможна гонка; `with lock:` защищает операцию. `start()` запускает потоки, `join()` дожидается их завершения.
3. Pydantic проверяет входные данные. `Field(gt=0)` запрещает неположительную цену, `default_factory=list` задаёт пустые теги. `POST /items` создаёт ответ с целочисленным `id`. Счётчик хранится в памяти: после перезапуска сервера снова будет `1`.
